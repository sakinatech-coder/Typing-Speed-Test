# ⌨️ Typing Master – Speed Test & Word Rain Game

A typing practice website built with **HTML, CSS and JavaScript** (no libraries).

## Features
### ⏱️ Speed Test
- Easy / Medium / Hard paragraphs
- 30, 60 or 120 second timer (starts on first key)
- Live WPM, accuracy and mistakes
- Green / red letter feedback
- Best WPM saved with localStorage

### 🎮 Word Rain Game
- Words fall from the top; type a word to destroy it
- 3 lives, score and increasing levels (faster + longer words)
- Pause / Resume and Restart
- High score saved with localStorage

### Extra
- Dark mode (remembered)
- Result popup
- Responsive for mobile and desktop

## How to run
Open `index.html` in any browser, or host it on GitHub Pages.

## Concepts used
DOM manipulation, events, `setInterval`, `requestAnimationFrame`, localStorage, array methods, CSS grid/flexbox, CSS variables.
