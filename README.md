# ⌨️ Typing Master – Speed Test, 4 Games & Stats

A typing practice website built with **HTML, CSS and JavaScript** only (no libraries).

## ⏱️ Speed Test
- **5 topics:** General, Programming, Student Life, Motivation, Code & Symbols
- **Passage length:** Short (~15 words), Medium (~35), Long (~70)
- **Modes:** 30 sec, 60 sec, 2 min, or "Finish the passage"
- Toggle punctuation and capital letters, choose text size
- Live WPM, accuracy, mistakes and progress bar
- Rank after every test (Beginner to Legend)

## 🎮 Games
| Game | How it works |
|---|---|
| 🌧️ Word Rain | Type falling words before they hit the ground (Easy / Normal / Hard) |
| 🔤 Letter Pop | Press the key to pop each falling letter |
| ⚡ Word Sprint | Type as many words as you can in 30 / 60 / 90 seconds |
| 🏁 Race vs Bot | Race a robot that types at 20 to 90 WPM |

## 📊 My Stats
- Best scores for every game
- Bar chart of the last 10 test results
- Recent activity table (saved with localStorage)

## Extra
- 5 colour themes, dark mode, optional key sounds
- Result popups, fully responsive

## Run
Open `index.html` in a browser, or host it with GitHub Pages.

## Concepts used
DOM manipulation, events, `setInterval`, `requestAnimationFrame`, localStorage, array methods, CSS variables, grid and flexbox, Web Audio API.
